# Upload Window

Estimate upload time with a user-specified effective throughput.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

File size (GB) = 4.5, Link speed (Mbit/s) = 20, Efficiency (%) = 75. The first result is 40.

## Limitations

The model uses the quantities and units shown beside each field. The printed and downloaded results reflect the current input values and displayed precision.
